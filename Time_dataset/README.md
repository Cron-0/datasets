# **Датасет №2**  
**Тип:** Временные ряды  
**Название датасета:** Перегрев подшипника  
**Исходные данные:** многомерные температурные временные ряды с датчиков  
**Формат данных (имя расширения файла):** zip архив с набором файлов формата .csv
## ****Задача:**** Разработать модель прогноза аномалии на основе трендов и градиентов температуры.
### ****Цель:**** Обнаружение неисправности за 10–30 минут до критического порога.
#### **Ссылка на датасет:** Ball Bearing Vibration, and Temperature Run-to-Falure Dataset - [https://data.mendeley.com/datasets/5hcdd3tdvb/6] (Итоговый датасет, используемый в коде, не обрабатывется в Google Colab полностью. Рекомендуется разбить датасет на два примерно одинаковых архива.)
