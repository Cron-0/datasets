# **Датасет №3**

**Тип:** Изображения  
**Название датасета:** Распознавание печатного и рукописного текста  
**Исходные данные:** Фотографии и сканы деловых корреспонденций  
**Формат данных (имя расширения файла):** Папка с файлами формата .xml и .tif

## **Задача:** Распознать и определить по входящим данным типы текста в корреспонденции

### **Цель:** Разметка корреспонденции по следующим критериям:

### 1): Корреспондент

### 2): Дата письма

### 3): Номер письма

### 4): Адресат

### 5): Подписант

#### **Ссылка на датасет:** Zenodo: RIMES (Reconnaissance et Indexation de données Manuscrites et de fac similÉS) - \[https://zenodo.org/records/10812725] (Для анализа использовалась папка DVD1\_TIF, но отдельно скачать без загрузки архива невозможно + загрузка в код через использование Google Disk)
