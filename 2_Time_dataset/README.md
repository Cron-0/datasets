# **Датасет №2**  
**Тип:** Временные ряды  
**Название датасета:** SKAB (Skoltech Anomaly Benchmark)  
**Исходные данные:** Многомерные временные ряды с датчиков испытательного стенда: вибрация (2 канала), ток, давление, температура корпуса двигателя, температура жидкости, напряжение, расход.  
**Формат данных (имя расширения файла):** zip-архив с набором файлов формата .csv
## ****Задача:**** Разработать модель для обнаружения аномалий и точек изменения состояния (changepoint detection) в работе оборудования.
### ****Цель:**** Создать алгоритм, который на основе анализа трендов и градиентов многомерных временных рядов сможет:
#### 1) Обнаруживать точечные аномалии (выбросы, outlier detection), сигнализирующие о резких нештатных отклонениях.
#### 2) Обнаруживать коллективные аномалии (смену состояния, changepoint detection), предсказывая переход системы в аварийный режим за 10–30 минут до критической точки.
