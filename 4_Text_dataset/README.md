# **Датасет №4**

**Тип:** Текстовые данные  
**Название датасета:** Распознавание печатного и рукописного текста  
**Исходные данные:** Новостные статьи на русском языке (текст) и их краткие содержания (резюме)  
**Формат данных (имя расширения файла):** .jsonl

## **Задача:** Сокращение длинной статьи до краткого пересказа (суммаризация)

### **Цель:** Разработать модель, способную по длинному тексту статьи генерировать краткое, содержательное резюме (саммари) на русском языке

#### **Ссылка на датасет:** Kaggle: Gazeta Summaries - [https://www.kaggle.com/datasets/phoenix120/gazeta-summaries]
